# 📖 Información General - Pokemon Trade

Información sobre el sistema, características y políticas.

---

## 🎯 ¿Qué es Pokemon Trade?

**Pokemon Trade** es una plataforma web segura donde usuarios pueden **comprar, vender e intercambiar Pokémon** de forma rápida y confiable.

### Descripción Breve

Imagina un marketplace (como eBay o Mercado Libre) pero especialmente diseñado para Pokémon. Aquí puedes:

- 📦 **Vender** tus Pokémon
- 🛍️ **Comprar** Pokémon de otros usuarios
- 💼 **Gestionar** todas tus transacciones
- 👥 **Conectar** con otros coleccionistas

---

## 🌟 Características Principales

### 1. **Sistema de Usuarios**
- Registro seguro con contraseñas encriptadas
- Dos roles: Comprador y Vendedor
- Perfil personalizado
- Historial de transacciones

### 2. **Catálogo de Pokémon**
- Base de datos con miles de Pokémon
- Filtrado por tipo, nivel y precio
- Fotos de cada Pokémon
- Información detallada

### 3. **Sistema de Compra**
- Búsqueda avanzada
- Carrito de compra
- Transacciones seguras
- Sistema de confirmación

### 4. **Sistema de Venta**
- Registro de Pokémon
- Gestión de precios
- Actualización de disponibilidad
- Aprobación de compras

### 5. **Transacciones**
- Sistema de aprobación en dos pasos
- Notificaciones en tiempo real
- Historial completo
- Seguimiento de estado

### 6. **Seguridad**
- Autenticación con sesiones
- Contraseñas encriptadas
- Validación de datos
- Protección contra accesos no autorizados

## ⚙️ Tecnología Utilizada

### Backend (Sistema)
- **Node.js**: Entorno de ejecución
- **Express**: Framework web
- **Sequelize**: Gestor de base de datos

### Base de Datos
- **MySQL / MariaDB**: Almacenamiento de datos

### Frontend (Interfaz)
- **Pug**: Motor de plantillas
- **Bootstrap**: Estilos visuales
- **jQuery**: Interactividad

### Seguridad
- **bcrypt**: Encriptación de contraseñas
- **JWT**: Autenticación de sesiones
- **express-session**: Gestión de sesiones
