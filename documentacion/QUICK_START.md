# ⚡ Guía Rápida - Pokemon Trade (Quick Start)

Una referencia rápida para empezar en 5 minutos.

---

## 🚀 Inicio Rápido

### 1️⃣ Registrarse

```
Dirección: http://localhost:3000
Botón: Crear Cuenta
Datos:
  - Correo: tu_email@example.com
  - Contraseña: MiPassword123!
  - Rol: Comprador o Vendedor
Haz clic: Registrarse
```

### 2️⃣ Iniciar Sesión

```
Correo: tu_email@example.com
Contraseña: MiPassword123!
Haz clic: Ingresar
```

### 3️⃣ Explorar

```
Ya estás dentro! Puedes:
- 👁️ Ver Pokémon disponibles
- 🛍️ Comprar Pokémon
- 📦 Vender Pokémon
- 💼 Gestionar transacciones
```

---

## 🛍️ Comprar en 3 Pasos

```
1. BUSCAR
   → Haz clic en "Lista de Pokémon"
   → Busca el que te interesa

2. SELECCIONAR
   → Haz clic en "Comprar"
   → Revisa los detalles

3. CONFIRMAR
   → Haz clic en "Confirmar Compra"
   → Espera aprobación del vendedor
```

---

## 📦 Vender un Pokémon en 5 Pasos

```
1. HAZ CLIC EN "Alta de Pokémon"

2. COMPLETA EL FORMULARIO:
   - Nombre: Pikachu
   - Tipo: Eléctrico
   - Nivel: 45
   - Precio: $150

3. SUBE UNA FOTO
   - Haz clic: "Seleccionar Foto"
   - Elige imagen JPG o PNG

4. HAZ CLIC: "Registrar Pokémon"

5. ✅ ¡LISTO! Ya está en venta
```

## ❓ Ayuda Rápida

### Mi contraseña no funciona
```
→ Verifica que esté correctamente escrita
→ Ten en cuenta mayúsculas/minúsculas
→ Contacta al administrador
```

### No encuentro un Pokémon que vi antes
```
→ Puede haber sido vendido
→ Intenta buscar similares
→ El vendedor puede haberlo eliminado
```

### ¿Cuánto demora una compra?
```
Entre 24-48 horas que el vendedor responda
```

### Mi Pokémon no aparece en búsqueda
```
→ Verifica que esté registrado correctamente
→ Recarga la página (F5)
→ Espera unos minutos a que se actualice
```
